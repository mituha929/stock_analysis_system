# 財務資料單位與口徑查證（2026-11-05）

## 範圍與方法

針對使用者標註的「標準化格式、數值單位與單季／累計口徑」，透過瀏覽器操作官方公開資訊觀測站，以同一公司、同一期間查詢，與 2026-11-05 13:20 保存的 API 樣本比對。這輪沒有重跑 12 個資料端點，也沒有修改正式程式或正式資料庫。

本次核對 M04／M05／M06 各一筆上市、一筆上櫃，共六個來源樣本；不是全公司或全欄位驗收。三大法人及融資券 M01～M03 不在本輪數值核對範圍。

官方來源與操作條件：

- [公開資訊觀測站：月營業收入](https://mops.twse.com.tw/mops/#/web/t05st10_ifrs)：自訂年度 115、月份 9，分別查 2330 台積電、6488 環球晶。
- [公開資訊觀測站：合併／個別報表](https://mops.twse.com.tw/mops/#/web/t164sb00)：分別查 1215 卜蜂、1584 精剛，結果期別均為 115 年第 3 季，檢視合併綜合損益表及合併資產負債表。
- [上市月營收欄位說明](https://data.gov.tw/dataset/18420)、[上櫃月營收欄位說明](https://data.gov.tw/dataset/56510)、[上市一般業損益表欄位說明](https://data.gov.tw/dataset/91998)：核對資料集身分與官方欄位名稱。

MOPS 使用查詢表單，網址不包含全部查詢條件；請依上列代號與期間重現。

## 最重要的口徑確認：抓到的是累計損益

MOPS 的合併綜合損益表同時提供「115 年第 3 季」與「115 年 01 月 01 日至 115 年 09 月 30 日」兩組欄位。已保存 OpenAPI 樣本對應後者。

| 公司 | 項目 | API 保存值 | 官網 1～9 月累計 | 官網第 3 季單季 | 結論 |
|---|---|---:|---:|---:|---|
| 1215 卜蜂 | 營業收入（仟元） | 21,866,426 | 21,866,426 | 7,464,783 | 累計相符 |
| 1215 卜蜂 | 基本 EPS（元） | 5.47 | 5.47 | 2.23 | 累計相符 |
| 1584 精剛 | 營業收入（仟元） | 1,708,467 | 1,708,467 | 624,011 | 累計相符 |
| 1584 精剛 | 基本 EPS（元） | 0.40 | 0.40 | 0.21 | 累計相符 |

因此未來樣本應明列 `period_basis = year_to_date`、期間起訖、`statement_scope = consolidated`。不能將原始值直接命名為單季營收或單季 EPS。單季 EPS 優先使用官方已公布的單季值，不將累計 EPS 相減當成通用換算方式。

資產負債表則對應 2026-09-30 的餘額，使用 `period_basis = point_in_time`，不能標成年初累計或單季流量。

## 同一資料集混合單位的實證

- 損益表的營業收入、營業利益、本期淨利採新台幣仟元；`基本每股盈餘（元）` 已是元／股，不能一起乘 1,000。
- 精剛資產負債表的資產 8,039,042 是仟元；`母公司暨子公司所持有之母公司庫藏股股數（單位：股）` 的 7,518,000 是股，不能當成仟元或張。
- 月營收金額為仟元；百分比欄為百分數值。例如 API 的 `-13.126055194406469` 對應官網顯示 `-13.13%`，不是資料錯誤，也不是 `-0.1313%`。

因此應以每個欄位的 `units` 註記，或採各欄位各自固定且有文件定義的單位契約。即使保留原始單位不換算，也必須讓下游知道其意義。

## 日期與缺值仍須分開

- `資料年月 = 11509` 是 2026-09 的營收期間；`出表日期 = 1151017` 是來源出表日期，不是 9 月營收所屬日，更不能直接視為公司最初公告日。
- 財報 `年度 = 115`、`季別 = 3` 表示財報期別，不是公告時間；本輪只確認損益期間與資產負債時點，沒有核對初次公告與修訂紀錄。
- API 空字串仍應保持未知／缺值，不能因官網某些欄位未列示就改填 0。只有明確提供的 0 才能當成零。
