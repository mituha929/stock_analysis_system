## 工具與保護

預覽（只 SELECT，不建立表）：

```powershell
.\.venv\Scripts\python.exe -B -X utf8 scripts\reset_day_integrity.py
```

實際清空，必須指定新的完整備份檔；以下檔名是示意，請勿覆蓋已有備份：

```powershell
.\.venv\Scripts\python.exe -B -X utf8 scripts\reset_day_integrity.py --apply --backup output\diagnostics\day-integrity-reset-NEW.jsonl.gz
```

執行時：

1. 取得與 API／CLI 相同的跨程序工作鎖；有工作執行時拒絕，不停止或搶走工作。
2. 確認驗收不在執行中，且已由使用者暫停或驗收設定已停用；不替使用者變更 `.env`、解除暫停、登入或重啟。
3. 確認兩表存在且為 InnoDB，沒有額外觸發器或參照外鍵，避免連帶影響其他資料。
4. 在可回滾交易中串流備份兩表**全部欄位與全部舊列**，保存欄位順序、筆數、原本控制狀態及 SHA-256，gzip 壓縮；不把百萬列一次載入記憶體。
5. 完整重讀備份、逐列核對筆數及雜湊後，才 `DELETE` 兩表。不使用不能回滾的 `TRUNCATE` 或 `DROP`。
6. 刪除筆數與備份不符或任何 SQL 失敗則回滾；提交連線異常則明確回報結果未確認，不盲目重跑。
7. 只清除本機控制中的驗收統計，不修改一般計畫、游標、run_id、暫停狀態或一般抓取統計。

備份含完整欄位標頭及逐列值，可供必要時還原到這兩張表。它不是 MySQL 全庫備份；還原前必須停止驗收、保留新紀錄並核對表結構，不能直接覆蓋後來的新驗收。
